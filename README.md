# Bare Compare support

Bug reports, feature requests and questions for [Bare Compare](https://barecompare.app),
the folder and file comparison tool from Fruit Salad Tech.

**No code lives here.** The application's source is private; this repository exists so
that reports have a public, structured home.

- **Something is wrong** → [open a bug report](https://github.com/frusal/bare-compare-support/issues/new?template=bug.yml).
  The form asks for the version (Help → About) and the platform, because those are the two
  things every investigation starts with.
- **Something should be better** → [request a feature](https://github.com/frusal/bare-compare-support/issues/new?template=feature.yml).
- **A question, or "how do I …"** → [Discussions](https://github.com/frusal/bare-compare-support/discussions).
- **Your licence, or a purchase** → email [support@barecompare.app](mailto:support@barecompare.app).
  Never post a licence key here: issues and discussions are public and indexed by search engines.

Email works for everything above too, if you would rather not use a GitHub account.
